Asset Inventory Helper

ソフトウェア資産の一覧を整形・可視化し、CSV/JSON形式で保存できます。

ソフトウェア一覧を入力

下のボタンで 入力例サンプル を読み込めます（Windows / Linux / macOS）。そのまま「整形して表示」を押して動作確認できます。

自動判定できないときは形式を選んでください。2列はTAB1個または2個以上の半角空白で区切ります。 単一空白では「1語の名前＋数字から始まる版」のみ読み取ります。名前だけの行は保留します。

入力は500,000 UTF-16コード単位、10,000行、結果は5,000件までです。 入力内容は外部送信・永続保存しません。公開ページの読込や外部リンクへの移動には通信が発生します。

整形結果

保存するのは採用した名前とバージョンだけです。保留・除外の行と元の行番号は含みません。 CSVは数式として扱われ得る先頭文字にアポストロフィーを付けます。表示や再保存時の扱いは表計算ソフトによって異なり、 完全な防止を保証しません。文字列として読み込み、元の値が必要な場合はJSONを使ってください。保存上限は10 MiBです。

取得のヒント（各OS）

コマンドは端末で実行します。このページが端末内を自動調査することはありません。 出力の形式や省略は環境で異なるため、採用結果と保留理由を確認してください。

Windows

  • winget: winget list（名前・ID・バージョンの見出しを含めて貼り付け）

Linux

  • Deb系: dpkg -l
  • RPM系: rpm -qa --qf '%{NAME}\t%{VERSION}-%{RELEASE}\n'（2列）

macOS

  • Homebrew: brew list --versions

通常のrpm -qa、system_profiler、Snap、CSV/JSON入力には対応していません。 取得コマンドの詳細と安全対策と限界も参照してください。
